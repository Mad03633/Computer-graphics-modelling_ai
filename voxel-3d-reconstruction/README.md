# Voxel-based 3D Reconstruction from Multi-view Images

This repository contains an implementation of **voxel-based 3D reconstruction from multi-view images**.

The project reconstructs a volumetric 3D representation of an object using multiple RGB images and silhouette masks rendered from different viewpoints. The reconstruction is based on a learnable voxel grid and differentiable volume rendering.

## Project Overview

The goal of this project is to reconstruct a 3D object as a voxel-based volume using multi-view image supervision.

Instead of reconstructing a surface mesh directly, the object is represented as a 3D grid of voxels. Each voxel stores:

- **density**, which describes whether the voxel belongs to the object;
- **color**, which describes the RGB appearance of the object.

A differentiable volume renderer is used to render the voxel representation from different viewpoints. The rendered images are compared with target RGB images and silhouette masks, and the voxel grid is optimized through gradient descent.

## Objective

The main objectives of this project are:

- to generate a multi-view dataset from a custom 3D object;
- to reconstruct a volumetric 3D representation from RGB and silhouette images;
- to investigate how the number of training iterations affects reconstruction quality;
- to compare reconstruction results after 150, 300, and 600 iterations;
- to analyze the effect of density regularization on the final volume.

## Dataset

A custom **rubber duck 3D model** was used instead of the default synthetic cow from the tutorial.

The dataset was generated by rotating the camera around the object and rendering it from multiple viewpoints.

The generated dataset contains:

```text
40 RGB images
40 silhouette images
```

  <img src="https://github.com/Mad03633/Computer-graphics-modelling_ai/blob/dev/voxel-3d-reconstruction/figures/rgb_silh_datasets.jpg"/>

Each view includes:

- an RGB image of the duck;
- a binary silhouette mask showing the object shape.

The RGB images provide color supervision, while the silhouette masks provide shape supervision.

## Methodology

### 1. Object Preparation

The data preparation process included:

1. Loading a textured `.obj` model of a rubber duck
2. Normalizing the object
3. Reorienting the object to match the coordinate system
4. Rendering the object from multiple camera viewpoints
5. Saving RGB images and silhouette masks

This multi-view dataset was then used as supervision for voxel reconstruction.

### 2. Voxel Representation

The object is represented as a learnable 3D voxel grid.

The model contains two main learnable components:

| Component | Purpose |
|---|---|
| Density grid | Represents object occupancy |
| Color grid | Stores RGB color values |

The model outputs:

```text
Density values in the range [0, 1]
Color values in the range [0, 1]
```

The density grid determines the 3D shape, while the color grid determines the appearance of the reconstructed object.

### 3. Differentiable Volume Rendering

For each camera viewpoint, rays are cast through the voxel volume.

The rendering process includes:

1. Sampling points along each camera ray
2. Reading density and color values from the voxel grid
3. Integrating density and color along the ray
4. Producing a rendered RGB image and silhouette

Because the renderer is differentiable, the reconstruction loss can be backpropagated into the voxel density and color grids.

## Loss Function

The model was trained using a combination of three loss terms:

```text
Loss = 2.0 * L_sil + 1.0 * L_rgb + 0.01 * L_reg
```

where:

- `L_sil` is the silhouette reconstruction loss;
- `L_rgb` is the RGB reconstruction loss;
- `L_reg` is the density regularization term.

### Loss Components

| Loss | Purpose |
|---|---|
| Silhouette loss | Enforces correct object shape |
| RGB loss | Enforces color consistency |
| Density regularization | Suppresses noise in empty space |

The silhouette loss is weighted more strongly because object shape is the most important component in 3D reconstruction.

## Training Setup

The model was trained with the following settings:

```text
Grid size: 32^3
Learning rate: 0.05
Ray samples per ray: 64
```

Three experiments were performed with different numbers of training iterations:

```text
150 iterations
300 iterations
600 iterations
```

Intermediate snapshots were saved every 50 iterations to visualize the reconstruction process. These snapshots were later combined into GIF animations.

## Experiments

### Experiment 1: 150 Iterations

At 150 iterations, the model learned the rough shape of the duck.

Observations:

- the main body structure became visible;
- the reconstruction was still unstable;
- the object shape was incomplete in some areas;
- some noise was visible in empty space.

### Experiment 2: 300 Iterations

At 300 iterations, the reconstruction became stable and visually accurate.

Observations:

- the overall duck shape was reconstructed well;
- the color distribution became more consistent;
- silhouette alignment improved;
- the result was clearer than at 150 iterations.

This was the best trade-off between quality and training time.

### Experiment 3: 600 Iterations

At 600 iterations, the model showed only minor improvement compared with 300 iterations.

Observations:

- the reconstruction was slightly smoother;
- the loss decreased only slightly;
- visual improvement was limited;
- additional training time did not significantly improve the result.

## Results

The training loss decreased quickly during the first 100 iterations. After approximately 150-200 iterations, the loss curve started to flatten.

This means that most of the useful learning happened in the early training stage.

<p align="center">
  <img src="https://github.com/Mad03633/Computer-graphics-modelling_ai/blob/dev/voxel-3d-reconstruction/figures/final_visual.jpg"/>
</p>

The final reconstruction successfully captured:

- the overall shape of the duck;
- the basic color distribution;
- the approximate 3D geometry;
- multi-view consistency.

However, some limitations remained:

- slight blurring caused by volumetric rendering;
- low-density noise in empty space;
- limited detail due to the `32^3` voxel resolution;
- transparent cube-like artifacts around the reconstructed object.

## Effect of Regularization

Density regularization improved the reconstruction by reducing unnecessary density in empty regions.

<p align="center">
  <img src="https://github.com/Mad03633/Computer-graphics-modelling_ai/blob/dev/voxel-3d-reconstruction/figures/effect_reg.jpg"/>
</p>

Benefits:

- reduced noise in empty space;
- clearer object boundaries;
- more distinct object shape.

However, too much regularization can be harmful.

Possible problems with excessive regularization:

- loss of object structure;
- overly transparent reconstruction;
- weak object density.

This shows that regularization must be balanced carefully.

## Main Findings

The project shows that voxel-based reconstruction can recover a meaningful 3D object from multi-view RGB and silhouette supervision.

Main conclusions:

- Multi-view images provide enough information to reconstruct approximate 3D geometry.
- Silhouette masks are very useful for learning the object shape.
- RGB loss helps recover basic appearance and color distribution.
- Most reconstruction improvement happens early in training.
- 300 iterations produced the best balance between quality and efficiency.
- Higher voxel resolution would be needed for finer details.

## Conclusion

This project successfully demonstrates voxel-based 3D reconstruction from multi-view images.

A learnable voxel grid was optimized using RGB reconstruction loss, silhouette loss, and density regularization. The reconstructed duck preserved the main object shape and basic color distribution.

The best practical result was achieved around **300 iterations**, where the reconstruction became stable while avoiding unnecessary extra training time.
