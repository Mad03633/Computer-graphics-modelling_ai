# 3D Deep Learning Projects

This repository contains a collection of projects focused on **3D deep learning, differentiable rendering, neural rendering, 3D reconstruction, object pose estimation, mesh prediction, and neural style transfer**.

The work was completed as a series of assignments and a final project. Each project explores a different 3D computer vision technique using modern deep learning libraries such as **PyTorch**, **PyTorch3D**, **Detectron2**, **Mesh R-CNN**, and **SynSin**.

## Overview

The main purpose of this repository is to demonstrate practical experiments with 3D computer vision models and differentiable rendering pipelines.

The projects include:

1. Surface reconstruction from noisy point clouds
2. Object pose estimation from silhouette using differentiable rendering
3. Pose estimation using silhouette and texture
4. CNN and Vision Transformer comparison for image classification
5. Voxel-based 3D reconstruction from multi-view images
6. Novel view synthesis with SynSin
7. 3D object detection with Mesh R-CNN
8. Neural texture style transfer on a 3D mesh with geometry preservation

Together, these projects cover both classical 3D representation methods and modern neural rendering approaches.

## Projects

### 1. Surface Reconstruction from Noisy Point Clouds

This project investigates how a smooth surface mesh can be reconstructed from a noisy point cloud.

A custom sofa-like 3D object was sampled into a point cloud of 5,000 points. Gaussian noise was added to simulate real-world scanning conditions. A spherical mesh was then deformed to match the noisy point cloud.

The reconstruction was optimized using:

- Chamfer distance
- Edge regularization
- Laplacian smoothing
- SGD optimizer

The experiments compared different regularization settings and showed that balanced regularization produces smoother and more stable reconstructions than using Chamfer distance alone.

Suggested repository name:

```text
noisy-point-cloud-surface-reconstruction
```

### 2. Object Pose Estimation from Silhouette using Differentiable Rendering

This project estimates the camera pose of a 3D object using only a silhouette image.

A guitar `.obj` model was loaded, normalized, simplified, and rendered using PyTorch3D. The camera position was optimized by minimizing the difference between the predicted silhouette and a target silhouette.

Main components:

- PyTorch3D differentiable renderer
- Soft silhouette rendering
- Camera parameter optimization
- MSE silhouette loss
- Adam optimizer

The experiment showed that silhouette information can be sufficient for accurate pose recovery when the object geometry is known.

Suggested repository name:

```text
silhouette-based-pose-estimation
```

### 3. Pose Estimation Using Silhouette and Texture

This project extends silhouette-only pose estimation by adding RGB texture information.

A textured guitar model was used. Since the original mesh did not include a predefined texture, a synthetic texture was generated by assigning random colors to mesh faces.

The project compared four loss settings:

| Experiment | Silhouette Weight | Texture Weight |
|---|---:|---:|
| Silhouette only | 1.0 | 0.0 |
| Texture only | 0.0 | 1.0 |
| Combined | 1.0 | 0.1 |
| Combined | 1.0 | 0.3 |

The best result was achieved with:

```text
w_silh = 1.0
w_tex = 0.1
```

The experiment showed that silhouette loss provides stable global shape alignment, while texture loss can improve appearance alignment if its weight is small.

Suggested repository name:

```text
texture-silhouette-pose-estimation
```

### 4. Comparative Analysis of CNN and Vision Transformer Architectures for Image Classification

This project compares **Convolutional Neural Networks (CNNs)** and **Vision Transformers (ViTs)** for image classification.

The analysis explains how CNNs and ViTs process images differently:

- CNNs use convolutional filters and local feature extraction.
- ViTs split images into patches and process them as token sequences using self-attention.

The project compares both model families in terms of:

- data requirements
- transfer learning
- fine-tuning stability
- computational efficiency
- global context modeling
- practical deployment

The conclusion is that CNNs are usually more practical for small datasets and limited computational resources, while ViTs become more powerful when large-scale pretraining and enough compute are available.

Suggested repository name:

```text
cnn-vs-vit-image-classification
```

### 5. Voxel-based 3D Reconstruction from Multi-view Images

This project reconstructs a voxel-based 3D representation of an object from multiple rendered views.

A rubber duck `.obj` model was used instead of the default synthetic cow. A dataset of 40 RGB images and 40 silhouette images was generated by rotating the camera around the object.

The object was represented using a learnable voxel grid with:

- density values
- RGB color values

The model was trained using:

```text
Loss = 2.0 * L_sil + 1.0 * L_rgb + 0.01 * L_reg
```

Training settings included:

```text
Grid size: 32^3
Learning rate: 0.05
Ray samples per ray: 64
```

The project compared 150, 300, and 600 training iterations. The best trade-off was achieved around 300 iterations, where the reconstruction became stable and additional training gave only minor improvements.

Suggested repository name:

```text
voxel-based-3d-reconstruction
```

### 6. Novel View Synthesis with SynSin

This project applies the pretrained **SynSin** model to novel view synthesis.

SynSin generates a new view of a scene from a single input image and a target camera transformation. The pretrained RealEstate10K checkpoint was used only for inference.

The tested images were:

- a chess piece
- a top-view scene with a book and a clock
- a close-up face portrait

The checkpoint used was:

```text
./modelcheckpoints/realestate/zbufferpts.pth
```

The project showed that SynSin performs best on scene-like images similar to RealEstate10K. It can still generate plausible views for simple object-centered images, but it struggles with strong domain shifts such as close-up faces and unusual top-view scenes.

Suggested repository name:

```text
synsin-novel-view-synthesis
```

### 7. 3D Object Detection with Mesh R-CNN

This project evaluates **Mesh R-CNN** for 3D object detection and single-image mesh prediction.

Mesh R-CNN extends Mask R-CNN by adding a 3D mesh prediction branch. It predicts:

- object class
- bounding box
- segmentation mask
- coarse voxel representation
- refined 3D mesh

The pretrained Pix3D Mesh R-CNN model was tested on:

- chair
- sofa
- out-of-distribution objects such as motorcycle/car

The model was launched using:

```text
demo/demo.py
configs/pix3d/meshrcnn_R50_FPN.yaml
```

The results showed that Mesh R-CNN works well for familiar Pix3D-like categories such as chair and sofa, but struggles with thin structures, fine details, and out-of-distribution objects.

Suggested repository name:

```text
mesh-rcnn-3d-object-detection
```

### 8. Neural Texture Style Transfer on a 3D Mesh with Geometry Preservation

This final project applies neural style transfer directly to the UV texture map of a 3D mesh while preserving the original geometry.

A ShapeNet chair model was used as the 3D object, and Edvard Munch's **The Scream** was used as the style image.

The method keeps the mesh geometry fixed:

```text
V = constant
F = constant
T = optimized
```

where:

- `V` is the set of vertices
- `F` is the set of faces
- `T` is the UV texture map

The project used:

- PyTorch3D differentiable rendering
- VGG19 feature extraction
- Gram matrix style loss
- Total variation regularization
- UV texture optimization
- foreground cropping using alpha masks
- ambient-only lighting

Compared with naive 2D style transfer, the UV-based method produces better multi-view consistency because the style becomes part of the shared 3D texture map.

Suggested repository name:

```text
neural-texture-style-transfer-3d
```

## Environment Setup

The projects were mainly developed in **Jupyter Notebook** with Python and GPU acceleration where available.

Because some libraries such as PyTorch3D, Detectron2, Mesh R-CNN, and SynSin are sensitive to Python, CUDA, and PyTorch versions, it is recommended to create separate environments for different groups of experiments.

## Installing PyTorch

Install PyTorch according to your CUDA version.

Example for CUDA 11.8:

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

For CPU-only installation:

```bash
pip install torch torchvision torchaudio
```

## Installing PyTorch3D

PyTorch3D installation depends on your Python, PyTorch, and CUDA versions.

A common installation approach is:

```bash
pip install pytorch3d
```

If this does not work, install it from the official wheel or from source.

Example:

```bash
pip install "git+https://github.com/facebookresearch/pytorch3d.git"
```

For Windows, PyTorch3D can be difficult to install directly. A practical approach is to use:

- WSL / Ubuntu
- Conda environment
- compatible CUDA version
- compatible PyTorch version

Recommended environment example:

```bash
conda create -n pytorch3d_env python=3.10
conda activate pytorch3d_env

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install pytorch3d
```

If `pip install pytorch3d` fails, use the official PyTorch3D installation guide for your system.

## Installing Detectron2

Detectron2 is required for Mesh R-CNN.

Example installation:

```bash
python -m pip install detectron2 -f \
https://dl.fbaipublicfiles.com/detectron2/wheels/cu118/torch2.0/index.html
```

The wheel URL must match your installed PyTorch and CUDA versions.

If the prebuilt wheel is not available, install Detectron2 from source:

```bash
git clone https://github.com/facebookresearch/detectron2.git
python -m pip install -e detectron2
```

## Installing Mesh R-CNN

Mesh R-CNN is based on Detectron2 and PyTorch3D.

Typical setup:

```bash
git clone https://github.com/facebookresearch/meshrcnn.git
cd meshrcnn
pip install -e .
```

After installation, use the Pix3D configuration:

```text
configs/pix3d/meshrcnn_R50_FPN.yaml
```

Example inference command:

```bash
python demo/demo.py \
  --config-file configs/pix3d/meshrcnn_R50_FPN.yaml \
  --input path/to/image.jpg \
  --output outputs/ \
  --onlyhighest
```

The `--onlyhighest` flag keeps only the highest-confidence prediction, which is useful for simple chair/sofa examples.

## Installing SynSin

SynSin was used for novel view synthesis with a pretrained RealEstate10K checkpoint.

Typical setup:

```bash
git clone https://github.com/facebookresearch/synsin.git
cd synsin
pip install -r requirements.txt
```

The pretrained checkpoint should be placed at:

```text
./modelcheckpoints/realestate/zbufferpts.pth
```

The model is then loaded in test mode and used for inference on custom images.

The input images are usually resized to:

```text
256 x 256
```

Then a camera transformation is applied to generate a novel view.

## Key Learnings

Across all projects, the main concepts learned were:

- how 3D objects can be represented as point clouds, meshes, voxels, and textures;
- how differentiable rendering connects 3D representations with 2D image losses;
- how silhouette loss can guide pose estimation;
- how texture loss can improve or destabilize optimization depending on its weight;
- how voxel grids can be optimized from multi-view supervision;
- how pretrained models such as SynSin and Mesh R-CNN behave under domain shift;
- how neural style transfer can be extended from 2D images to 3D mesh textures;
- how model performance depends on data domain, representation choice, and regularization.

## Conclusion

This repository demonstrates a broad set of 3D computer vision and deep learning techniques.

The projects show how different 3D representations can be optimized or predicted using neural networks and differentiable rendering:

- point clouds can be reconstructed into surfaces;
- silhouettes can recover camera pose;
- RGB texture can help pose alignment when used carefully;
- voxels can reconstruct 3D geometry from multiple views;
- SynSin can synthesize new views from a single image;
- Mesh R-CNN can predict coarse 3D meshes for known categories;
- UV texture maps can be optimized for 3D neural style transfer.

Overall, the work provides practical experience with modern 3D deep learning pipelines and highlights both their potential and their limitations.
